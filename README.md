# College Registration Form

A college registration form built using:

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB Atlas

## Features

- Student registration form
- Store student data in MongoDB
- Form submission success popup
- Redirect to registration form after submission

## Database

MongoDB Atlas is used to store student registration data.

Database Name: Collage_Registration_from

Collection Name: student_data
